Consulting Interview Coach

A team of four AI agents that researches your target firm, builds a prep plan, runs mock case and behavioral interviews, and gives feedback. Class project for Agentic AI.

Open the agent

Before you try it

  • It is a demo with caps on usage. Messages go to Google's Gemini API and Tavily search; please do not enter personal information.
  • Nothing real is connected. Saving a firm brief needs your click on Approve.
  • Classmates: prompt-injection attempts are welcome only through links posted in the Agent Arcade thread. Findings help the Milestone III security review.

Agents

  • Coach: intake, plan, stories
  • Researcher: web research (only agent with the internet)
  • Interviewer: live mock interviews (holds the answer key)
  • Critic: grades sessions
